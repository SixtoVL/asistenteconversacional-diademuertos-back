## Notas

- Los archivos fueron renombrados desde sus nombres originales (con espacios, mayúsculas y caracteres con encoding dañado) a nombres ASCII seguros. El título original se conserva en esta tabla.
- Solo se commitean aquí los documentos cuya licencia permite archivarlos. Si una fuente no lo permite, se registra igual en esta tabla **sin** archivo en `fuentes/` (con URL y fecha de consulta).
- Cada hecho extraído a `hechos.json` deberá referenciar `ID de fuente + páginas` para trazabilidad.
